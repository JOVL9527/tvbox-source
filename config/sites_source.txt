# =============================================================================
# 点播源聚合来源 —— 公开 TVBox 配置(JSON / JSONC)
# -----------------------------------------------------------------------------
# 本工具会逐个抓取这些配置，从中提取四样东西并跨源合并：
#   sites   —— 点播资源站（影视接口）
#   spider  —— 爬虫包地址（csp_ / js 类站点必须依赖它），按「出现次数最多」自动选出
#   parses  —— 播放解析接口，去重后合并
#   flags   —— 播放线路标记，去重后合并
#
# 每行一个地址，# 开头为注释。建议保留 5~7 个「更新活跃 + 站点质量高」的来源，
# 来源越多重复率越高、耗时也越长。
# 以下均已在 2026-10-16 实测：HTTP 200 且可被解析（含 JSONC 注释写法）。
# 工具已支持：BOM、// 与 /* */ 注释、尾部多余逗号；遇到加密配置会自动跳过并告警。
# =============================================================================
